# SELF / NON-SELF

**A 13-minute animated film about the last immune cell of a dying body. Drawn live in TypeScript. No video, no images, no recorded sound.**

**Watch:** <https://lucagandolfi77.github.io/random2/self-non-self/>

> *I was made to carry a warning. I am sorry it arrives so late.*

Portrait-first · 10 chapters · English / Italiano · procedural score · installable and offline.

---

## The film

Inside a human body that is dying, the last **dendritic cell** — the immune system’s messenger — carries the memory of everything the body has survived. The oxygen falls. The bone marrow stops sending reinforcements. The gut barrier fails, and the body’s oldest residents, the microbiome, cross into the blood.

The cell cannot save the body. There is no cure, no rescue, no last-minute immunity. The only question is what the last message means.

The residents are not villains. They were the body’s first guests, tolerated since birth; the immune system is not only a wall, it is also the art of knowing what to let in. When the energy to draw the border runs out, the cell’s final act is not victory. It is hospitality.

The last signal is not a warning. It is an invitation: **come in**.

And in the final title, the slash in **SELF / NON-SELF** softens into a comma — a border becoming a breath.

### The pronoun arc

The film moves from **I** → **you** → **we** → silence. The cell begins as a servant of the body’s sovereignty and ends as a guest of the world it was built to exclude.

> *The body is not a fortress. It is a garden that learned, for a little while, to say I.*

### The science

The immune system does not only fight. It learns **tolerance**: the daily, metabolic act of deciding what belongs. Dendritic cells sample tissue, carry antigens to lymph nodes, and teach T cells what is self and what is not.

In a dying body, barrier failure can let gut bacteria translocate into the blood. The residents in this film are not villains; they are survivors. This is poetic biology, not medical advice.

Content note: the film depicts the death of a body, illness and grief. There is no graphic imagery and no rapid flashing. Captions are on by default.

## How it is made

- **TypeScript + Vite, zero runtime dependencies.** Canvas 2D for the picture, Web Audio for the score, the browser for everything else.
- **A single deterministic timeline.** Every frame is a pure function of time; randomness is seeded per shot. Scrubbing, pausing, resuming and deep links are frame-exact.
- **A reusable shot grammar.** Cells, bacteria, antibodies, collagen, villi, alveoli and vascular networks are drawn procedurally; 45 shots are composed from those primitives.
- **The score is the dying body.** The tempo follows the heart rate from 64 BPM to 39, then to three final beats. After that, the score outlives the body by a single phrase. The body theme is five descending notes; the messenger’s theme is three rising ones. The residents’ 7/8 pizzicato is curious, not sinister, and inherits the messenger’s theme at the end.
- **No assets.** No video files, no images, no recorded music, no remote requests. The PWA icons are generated by `scripts/gen-icons.mjs` with a hand-written PNG encoder.
- **Bilingual by construction.** All poetry and dialogue live in `src/film/script.ts` with paired English and Italian text; captions can switch mid-film.
- **Portrait-first.** A 9:16 virtual stage; the frame fills a phone and becomes a tall lightbox on desktop. The canvas is rendered at up to 2.2 megapixels with adaptive grain.
- **Accessible.** Captions on by default, keyboard controls, `prefers-reduced-motion`, no flashing above 3 Hz, ARIA labels, safe-area insets, installable offline.

### Player

- Tap the poster to begin with sound, or choose silence.
- Tap the picture to bring the controls back.
- `Space` play/pause · `←`/`→` 10 seconds · `C` captions · `M` mute · `F` fullscreen.
- The progress line is the film’s membrane: tap or drag it, or open the chapter sheet.
- The language pill switches **English / Italiano** everywhere, including mid-film. The choice is remembered.
- The film resumes where you left it; share links open at the current timestamp.
- Installable and offline after the first viewing.

## Development

Requires Node.js `>=20.19` and npm.

```bash
npm ci
npm run dev        # http://127.0.0.1:5173/
npm run typecheck
npm test           # timeline, bilingual and determinism tests
npm run build      # production build in dist/
npm run preview    # http://127.0.0.1:4174/
```

The build uses relative asset paths (`base: './'`), so the same `dist/` works at a domain root, under `/random2/self-non-self/`, or from a plain static server.

## Deployment

The repository’s Pages workflow builds the film and copies `dist/` to `/self-non-self/`:

```yaml
- name: Build SELF / NON-SELF
  working-directory: self-non-self
  run: npm ci && npm run typecheck && npm test && npm run build
```

The site is served under:

**https://lucagandolfi77.github.io/random2/self-non-self/**

The service worker scope is relative, so it follows the sub-path automatically. If the film moves to its own repository, publish `dist/` at the root; no code changes are required.
