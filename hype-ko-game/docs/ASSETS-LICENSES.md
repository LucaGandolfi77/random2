# Asset licenses

HYPE K.O. — THE LAST VIRALITY does not ship third-party character models, textures, music or sound effects. Characters, arenas, VFX and audio are generated at runtime. The only bundled third-party binary assets are the two open-source fonts documented below.

## Original game assets

| Asset group | Source | License |
| --- | --- | --- |
| Character designs, names, bios, quotes, rivalries | Original work in this repository | Same license as this project |
| 3D character rigs, outfits, hair, accessories | Procedurally generated with Babylon.js primitives (`src/game/engine/character.ts`) | Same license as this project |
| Arenas, props, crowds, backdrops | Procedurally generated with Babylon.js primitives (`src/game/engine/stage.ts`) | Same license as this project |
| VFX sparks, rings, beams, explosions | Procedurally generated (`src/game/engine/vfx.ts`) | Same license as this project |
| Music and SFX | Synthesized at runtime with the Web Audio API (`src/game/audio/audioManager.ts`) | Same license as this project |
| Announcer voice | Browser `SpeechSynthesis` API (system voice, not bundled) | Provided by the browser/OS |
| PWA icons | Generated by `scripts/generate-icons.mjs` using a hand-written PNG encoder | Same license as this project |
| UI layout and CSS | Original work in this repository | Same license as this project |

## Runtime APIs

- **WebGPU** and **WebGL2** — browser-provided rendering APIs.
- **Web Audio API** — browser-provided audio synthesis.
- **SpeechSynthesis** — browser/OS-provided speech synthesis. No voice data is recorded or transmitted.
- **localStorage** — browser-provided local persistence.
- **WebSocket** — browser-provided networking.

## Explicitly not used

- No ripped game assets, sprites, models or audio from commercial fighting games.
- No stock photography or third-party artwork.
- No user tracking, advertising SDKs, analytics or fingerprinting.
- No remote asset downloads at runtime; the game works offline after the PWA shell is cached.

If you fork this project and add third-party assets, document their license here and ensure you have redistribution rights.
