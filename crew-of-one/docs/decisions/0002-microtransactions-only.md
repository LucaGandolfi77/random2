# ADR 0002 — Microtransactions only

## Status
Accepted.

## Context
The game is free to download. Revenue must come from in-game purchases, not ads or an upfront price.

## Decision
Free prologue + free daily heist. Paid chapter unlocks, full-campaign bundle, cosmetics, supporter pack. No ads, energy, gacha, loot boxes, or pay-to-win.

## Consequences
- Requires volume and a strong demo funnel.
- Web checkout at launch via Lemon Squeezy.
- Mobile IAP via RevenueCat.
- Leaderboard remains free and fair.
- If conversion is weak, test a single Full Unlock IAP after soft launch.
