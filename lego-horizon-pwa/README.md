# LEGO Horizon Adventures — Fan Store

A mobile-first, installable **fan-made clone of a Steam store page** for LEGO
Horizon Adventures. It keeps the familiar store layout — hero, review pill,
tags, editions, specs, language table — but all of the imagery is **original
SVG concept art** drawn for this demo. No official screenshots, logos or
trailers are used, and no real purchases take place.

## Run it

```bash
python3 -m http.server 8080
# open http://localhost:8080/lego-horizon-pwa/
```

Plain static files with relative paths. No build step, no dependencies, no
external requests at runtime. After the first load the whole page and every
illustration work offline.

## What's inside

- Steam-inspired dark UI tuned for a 360–430 px viewport, with safe-area
  insets, 44 px touch targets and a sticky bottom purchase bar.
- Seven original SVG concept scenes plus a cover illustration and a custom
  brick/horizon app icon, all generated by `scripts/gen-art.mjs`.
- Swipe-snap gallery with a fullscreen lightbox (swipe, arrows, Escape).
- Wishlist and cart persisted in `localStorage`; edition picker, cart sheet and
  a clearly labelled demo checkout.
- Web Share API with clipboard fallback.
- **Play Machine Hunt**: an original top-down mini-game with a village hub,
  upgrades, one active companion bot, three waves and a three-phase Tallneck
  boss. Includes pooled particles, screen shake, hit-stop, floating damage
  numbers, a procedural music bed, layered SFX, first-run coach marks and a
  settings panel (sound, music, haptics, reduced motion).
- **Daily hunt:** a date-seeded run with a local best, streak and daily wins.
- **Missions & stats:** five persistent missions with core rewards, an
  accuracy / combo / playtime / streak record panel and a ghost trail from
  your best run.
- **Shareable score card** rendered on canvas, shared with Web Share or copied
  to the clipboard.
- **Controls & accessibility:** drag, virtual stick and one-hand schemes, aim
  assist, sensitivity, colourblind/contrast palettes, gamepad support and an
  aria-live score/health announcer.
- **Living village:** drag decorations onto a 5×3 grid, tap villagers for
  dialogue, and complete a seeded daily community-board bounty. Lanterns glow
  at night; the scene tints after 19:00.
- **Combat foundation (Phase A1):** four weapons (Bow, Spear, Bomb Sling,
  Trap Kit) with basic/charged/ultimate attacks, stamina and a dodge roll with
  i-frames, plus freeze/shock/burn/stun status effects with enemy resistances.
- **World expansion (Phase A2):** 12 machine types including pack-hunting
  Stalkers, diving Flyers and charging Bruisers; four bosses with data-driven
  phase scripts; four biomes with seeded hazards (lava, quicksand, ice, spikes).
- **Modes (Phase A3):** a world-map hub with Campaign (eight chapters), Daily,
  Endless Gauntlet and Boss Rush; mode-aware HUD and results.
- **RPG progression (Phase B):** hunter levels and XP, three five-tier skill
  branches, four craftable gear pieces with rarities, scrap/bricks/parts
  materials, companion training, two active companion slots with synergy, and a
  five-quest log.
- **Living world (Phase C):** a 24-slot village grid with 20 buildings,
  villager jobs with real-time offline production (capped at eight hours),
  a four-chapter story with village-changing choices, daily seasonal events and
  time-of-day villager schedules.
- **Full app (Phase D):** a dedicated installable `play/` app with its own
  manifest and service worker, ten-week local seasons with prestige,
  achievements, shareable challenge codes, save export/import, opt-in daily
  notifications, EN/IT UI and adaptive music.
- **Hardening (Phase E):** deterministic balance bot with difficulty reports,
  input-replay / bug-report codes, device-tier adaptive quality, a PWA audit
  script and CI-style visual-baseline checks.
- **Quality hardening:** fixed-timestep simulation, pooled effects, tab-hide
  pause, save fuzzing, a `?debug=1` HUD and visual-baseline screenshots.
- PWA manifest, versioned service-worker precache, install prompt on
  Android/desktop and an Add-to-Home-Screen guide on iOS.
- Factual store metadata (price €39.99 / €49.99, Mixed 60% of 407 reviews,
  25 languages, system requirements) captured on 16 Nov 2026. The long
  description is an original paraphrase, not Steam's marketing copy.

## Regenerate art

```bash
npm run assets
```

This rewrites the generated SVGs, PNG icons, `og-cover.png` and the three
manifest screenshots. The generated files are committed; the app does not run
the scripts at runtime.

## Play the demo

Three buttons open the game: in the hero, in the bottom bar and in the
Overview card. The game is lazy-loaded on the first tap but precached, so it
also works offline.

- **Controls:** drag anywhere to move relative to your touch-down point; the
  current weapon auto-fires at the nearest machine; tap or hold for a charged
  shot, or spend stamina on an ultimate. Swap weapons with 1–4 or the HUD
  buttons, dodge with Shift/double-tap/gamepad B, use **U** for an ultimate.
  Choose **Stick** or **One-hand** in the village for a virtual stick and charge
  button. Keyboard: WASD/arrows, Space, Escape.
- **Village:** spend brick cores on Bow / Quiver / Armour / Boots upgrades and
  four permanent plots (Workshop, Garden, Banner, Lookout). Unlock up to three
  companion bots and bring one on each hunt.
- **Hunt:** three waves of scouts and grazers, plus Lancers, shield-bearing
  Bulwarks and burrowing ambushers at higher levels. Seeded wave modifiers
  (swift, armoured, swarm) and a three-phase Tallneck boss with guards,
  shockwaves and enrage. Win to earn cores and raise the hunt level; a loss
  keeps half the cores you collected. Progress persists in `localStorage` with
  a Reset progress button.
- **Modes:** pick a mode on the world map. Campaign chapters unlock as you
  clear them; Daily is seeded per date; Endless keeps sending waves with a boss
  every fifth; Boss Rush chains three bosses. The HUD and results show the mode.
- **Debug:** add `?debug=1` to the page URL to see FPS, frame time, entity and
  pool counts, the run seed and the active control scheme.

## Test

```bash
npm test
npm run smoke   # with a local server on 8080
```

111 node checks cover the store page, PWA contract, effects pooling, combat,
boss scripts, biomes/hazards, modes, RPG progression, crafting, companion
synergy, living-world production, seasons, story choices, achievements, season
prestige, challenge/save codes, replays, device quality tiers, localisation,
game simulation, daily streaks, missions, village placement, bounty rewards,
save migration and input helpers. The Chromium smoke test runs 55 checks,
including the challenge/language UI, world map, skill tree, crafting bench,
villager jobs, story dialog and an **offline game boot**.

```bash
npm run balance -- 300       # deterministic balance report (JSON)
npm run audit                # PWA meta/offline audit of both entries
npm run shots:check          # visual-baseline size/dimension diff
```

The standalone `play/` app has its own visual baseline. All tooling skips
cleanly when Chromium is unavailable. `npm run shots` writes four visual
baselines into `screens/qa/`.
