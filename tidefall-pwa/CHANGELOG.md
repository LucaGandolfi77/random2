# Changelog

## 0.5.0 - World regions and exploration journal

- Added region boundaries to the tactical minimap and live region identity to the HUD.
- Fixed keyboard collect/repair state to remain active while keys are held.
- Bumped the offline cache for installed clients.

## 0.4.0 - World exploration and presentation pass

- Added four named sea regions with distinct threat tiers.
- Added three lore landmarks and three persistent salvage wrecks.
- Added chart discovery rewards and journal entries for locations and wreck recovery.
- Improved sea rendering with camera-bounded animated waves, shimmer and target markers.
- Added shared deterministic math helpers and corrected mouse navigation input ownership.

## 0.3.0 - Naval activities and combat systems

- Added round, chain, cinder and harpoon ammunition with limited stock and harbor resupply.
- Added field repair ability with cooldown and touch controls.
- Added two huntable sea monsters with rewards and persistent defeat state.
- Added timed treasure charts, salvage rewards, world event notices and captain bounties.
- Added combat HUD state and feature tests.

## 0.2.0 - Story and extended gameplay

- Added a three-chapter campaign with sequential contracts and rewards.
- Added four ports, contextual dockside dialogue, market, ship repair and upgrades.
- Added cargo trading, captain XP/levels, faction standing and a captain journal.
- Added IndexedDB autosaves, offline elapsed-time updates and save import/export.
- Added automated world economy and campaign progression test.

## 0.1.0 - Milestone 1

- Added TIDEFALL single-player naval RPG prototype.
- Added procedural Canvas renderer, mobile HUD and virtual controls.
- Added inertia movement, tap navigation, targeting, cannon combat and salvage.
- Added personality-driven AI captains for merchants, pirates and hunters.
- Added IndexedDB persistence with localStorage fallback.
- Added PWA manifest and cache-first service worker.
