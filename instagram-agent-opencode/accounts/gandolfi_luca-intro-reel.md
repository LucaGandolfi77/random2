# Intro reel: the mock trailer

Pinned profile asset. 20-22 seconds. No talking head. Built from clips that
already exist, plus title cards. Shoots in one sitting.

**Purpose:** a stranger arriving from one reel should understand in one watch
that there is more of this, and that it is shot like a film.

specific and self-deprecating, but the mock-trailer format is what carries it.
